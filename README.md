# SOC SIEM Log Investigation Lab

## Project Overview
This project focuses on developing practical SOC Analyst skills by collecting, analyzing, and investigating security logs using Splunk.

The goal is to understand how security analysts identify suspicious activities and investigate potential security incidents.

## Objectives
- Learn how SIEM platforms work.
- Import and analyze sample security logs.
- Identify suspicious login attempts.
- Investigate unusual account activity.
- Practice writing basic security incident reports.

## Tools
- Splunk
- Windows Event Logs
- GitHub

## Planned Investigations
1. Repeated failed login attempts.
2. Suspicious account activity.
3. Unusual login behavior.
